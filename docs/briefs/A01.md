# A01: Scaffold the repo

Status: ready
Depends on: none (the repository and its hygiene files already exist)
Task in TASKS.md: A01

## Goal

Give every later task a skeleton that runs: an API and a web app that start locally, test and lint commands that work on Windows, and CI that runs the same checks on every pull request so reviews have hard evidence. No product features yet.

## Scope

**In:**
- `api/`: FastAPI app with a health route, settings loaded from env, a seed stub, one test, lint and type-check config
- `web/`: Next.js app (App Router, TypeScript, Tailwind CSS, shadcn/ui) with a placeholder shell that shows the API's health
- `.github/workflows/ci.yml`: API and web checks on every pull request and push to `main`
- The commands section of `AGENTS.md`, filled in with the real commands

**Out** (later tasks own these):
- Domain schemas and routes (A03)
- The Meta API client and smoke test (A02)
- Database models and seed data (A03, A16)
- Any screen beyond the placeholder shell (A08 onward)

## Design

**Files and owners:**

| File or folder | Owner | What goes in it |
| --- | --- | --- |
| `api/` | subagent 1 | FastAPI app, settings, seed stub, tests, `requirements.txt`, `requirements-dev.txt`, `pyproject.toml` |
| `web/` | subagent 2 | Next.js app and its config |
| `.github/workflows/ci.yml`, `AGENTS.md` commands section, README "Run it locally" and third-party table | main session, after both subagents finish | CI and docs |

**API layout:**

```
api/
  app/__init__.py
  app/main.py        FastAPI app; CORS allows http://localhost:3000; GET /health
  app/config.py      Settings (pydantic-settings) read from the repo-root .env
  app/seed.py        `python -m app.seed` prints "Nothing to seed yet" and exits 0
  tests/test_health.py
  requirements.txt
  requirements-dev.txt
  pyproject.toml     ruff, mypy and pytest config
```

- `GET /health` returns `{"status": "ok", "demo_mode": "<DEMO_MODE>"}`.
- `Settings` fields: `model_api_key` (optional at startup, so the app and tests run without a key), `meta_base_url` (default `https://api.meta.ai/v1`), `model_read`, `model_impact`, `model_transcribe` (defaults as in `.env.example`), `demo_mode` (`live` or `replay`, default `live`). Model IDs are only ever read from here; nothing else hardcodes them.
- Python 3.12. The commands must match the README's "Run it locally" section (`pip install -r requirements.txt`, `python -m app.seed`, `uvicorn app.main:app --reload --port 8000`).

**Web layout:**

- Create with the current stable `create-next-app` (TypeScript, Tailwind, ESLint, App Router, `src/` off). Don't pin a guessed version.
- Initialize shadcn/ui.
- Home page: the product name, four placeholder links (Triage, Solicitation, Quotes, Orders) and an "Ask KounOS" placeholder panel, plus an API status line that calls `${NEXT_PUBLIC_API_URL}/health` and shows "API: ok" or "API: unreachable".
- `package.json` scripts: `dev`, `build`, `lint`, `typecheck` (`tsc --noEmit`). `engines.node` is `>=20`.

**CI** (`.github/workflows/ci.yml`), on `pull_request` and on `push` to `main`:
- API job: Python 3.12, install both requirements files, then `ruff check`, `mypy app`, `pytest`.
- Web job: Node 20, `npm ci`, `npm run lint`, `npm run typecheck`, `npm run build`.

## Acceptance criteria

- [ ] `pytest` passes in `api/`, including a test that `/health` returns 200 with `status: ok` (evidence: pytest output)
- [ ] The API starts with no `.env` present and no API key set (evidence: uvicorn startup log and a `curl` or browser hit on `/health`)
- [ ] `ruff check` and `mypy app` pass (evidence: command output)
- [ ] `npm run lint`, `npm run typecheck` and `npm run build` pass in `web/` (evidence: command output)
- [ ] With both running, the home page shows "API: ok"; with the API stopped, it shows "API: unreachable" (evidence: two screenshots)
- [ ] CI is green on this pull request (evidence: the checks on the pull request)
- [ ] `AGENTS.md` commands section lists the real commands, and the README's "Run it locally" still matches them
- [ ] No model ID appears anywhere except `.env.example`, `app/config.py` defaults and docs (evidence: a repo search)
- [ ] No `.env`, secrets or build output committed; `.agents/memory/` stays ignored
